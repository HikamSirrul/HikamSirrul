## 🚀 Featured Projects

### 🩸 Blood Donor Eligibility Classification System

A web-based application that classifies prospective blood donors as eligible or ineligible using a Naive Bayes machine learning algorithm.

**Key Features**
- Machine learning-based donor eligibility classification
- Integration of a trained model into a Flask application
- Data management using MySQL
- Web interface for medical personnel

**Tech Stack:** Python, Flask, Scikit-learn, Pandas, MySQL

### 🤰 BumpCare

A web application designed to support pregnancy health monitoring through pregnancy risk classification and nutritional status assessment.

**Key Features**
- Pregnancy risk classification
- Maternal nutritional status assessment
- User authentication and data management
- Integration of web technologies with machine learning

**Tech Stack:** React, Hapi.js, PostgreSQL, JWT, TensorFlow

### 💰 FinTrack

A personal finance management application designed to help users organize financial transactions and monitor their accounts.

**Key Features**
- Financial dashboard
- Account and transaction management
- Income and expense categorization
- Money transfers between accounts
- Authentication and backend API integration

**Tech Stack:** React, TypeScript, Tailwind CSS, Express.js, Prisma, PostgreSQL
